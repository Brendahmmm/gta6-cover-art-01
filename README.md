Neon Cover Studio turns your photos into GTA-style cover art: multi-panel posters with bold caption lettering and Vice City sunset or neon grades, exported as PNG in 1080×1080, 1080×1350 and 1920×1080. Upload your own photos, crop and position each one, pick a layout and a grade, and export — everything runs offline from static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
